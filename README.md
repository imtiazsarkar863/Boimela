# বইমেলা | Boimela 📚

**A Bengali digital reading platform for book lovers.**

বইয়ের ন্যায় একগুচ্ছ অনুভূতি

Boimela is a web development project designed to bring books and reading-related content together in one place. Users can explore a curated collection of books, view PDFs directly on the website, and watch accompanying videos.

🌐 **Live Demo:** https://boimela-woad.vercel.app/

## ✨ Features

- 📚 Book-focused landing page and collection
- 📄 Embedded PDF viewing
- 🎥 Embedded YouTube videos accompanying books
- 🇧🇩 Bengali typography and content
- 🎨 Custom-designed interface using CSS and Tailwind CSS
- ☁️ Deployed on Vercel

## 🛠️ Tech Stack

- **Frontend:** React
- **Build Tool:** Vite
- **Styling:** Tailwind CSS v4 and custom CSS
- **PDF Storage:** Google Drive
- **Deployment:** Vercel
- **Version Control:** Git and GitHub

## 🚀 Run Locally

### Prerequisites

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate into the project directory:

   ```bash
   cd boimela
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
